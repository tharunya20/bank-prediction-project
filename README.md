# Bank Prediction Project

A Machine Learning based Bank Prediction Web Application built using Flask and XGBoost.

## Features

- Machine Learning prediction
- Flask backend
- Attractive frontend UI
- Live deployment on Render
- GitHub integration

## Technologies Used

- Python
- Flask
- XGBoost
- HTML/CSS
- Git & GitHub
- Render
